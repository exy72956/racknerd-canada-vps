## 到国内延迟 232ms 左右，电信比联通稳

第三方测评给出的三网数据：全国平均约 **232ms**，电信约 **210ms**，联通约 **238ms**，移动约 **251ms**，港澳台约 **203ms**。这是第三方实测口径，你所在省份和运营商的实际数字会有出入。

路由上，三网去程都从上海出口，先落到美国东部，再转去多伦多。有测评直接指出这条线不是中国优化线路，延迟比洛杉矶、圣何塞高一截，符合地理位置的实际。

稳定性方面，第三方测评的说法是电信和移动相对稳定，联通丢包偏多。联通用户如果只是建站给北美访客看，这个丢包影响有限；如果是自己每天 SSH、传文件、跑同步，体验会明显打折，这种情况建议考虑洛杉矶 DC-02 或圣何塞节点。

两个对建站和邮件更有用的细节，来自第三方测评：多伦多这批机器给的是**美国原生 IP**，并且**开放 25 端口**。要发 transactional mail、接需要美国 IP 的第三方服务，这两点比 230ms 的延迟值钱得多，也是很多只看价格的测评不会提的地方。
